Como registrar

  1. Clique em Registrar progresso (ou aperte a tecla N).
  2. Escolha o tipo, escreva o que fez e a categoria.
  3. Toque em Salvar: o registro aparece na hora no painel.
  4. Ele é enviado ao GitHub em segundos e fica guardado, mesmo se a internet cair.
  5. Para corrigir ou apagar, use Editar e Excluir em cada registro.

Conexão

Conectar ao GitHub

Para o painel salvar sozinho no seu repositório, crie um token de acesso. É só uma vez por navegador.

✅ Conectado ao GitHub. Seus registros são salvos direto no repositório.
  1. Abra a página de criação do token.
  2. Em Repository access, escolha Only select repositories e marque swartz-progress-panel.
  3. Em Permissions → Repository permissions → Contents, escolha Read and write.
  4. Clique em Generate token, copie o código e cole aqui embaixo.

O token fica guardado só neste navegador e só vai para o GitHub. Dá para revogar quando quiser nas configurações da sua conta.

Atenção

Excluir este registro?
